# BoW vs TF-IDF for Sentiment Analysis

## Objective

Compare Bag of Words and TF-IDF feature extraction methods for sentiment analysis using Logistic Regression.

## Dataset

IMDb Movie Reviews Dataset

5,000 reviews

Positive / Negative

## Technologies

- Python
- Pandas
- NumPy
- Scikit-learn

## Models

- Bag of Words + Logistic Regression
- TF-IDF + Logistic Regression

## Evaluation Metrics

- Accuracy
- Precision
- Recall
- F1 Score

## Run

Install dependencies

```bash
pip install -r requirements.txt
```

Run

```bash
python main.py
```
